🟢 Google Drive backup — your blueprint, implemented off

No extra Supabase needed. Register projects → auto-backup to your own Google Drive (hidden app-data folder only this console sees). On new phone: sign in → Connect → 📥 Restore → continue monitoring. Client ID ships in repo (assets/js/gdrive-config.js — safe: public by design, locked to your URL by Google), so nothing typed on new devices. Filenames carry project count (…-p12.json), restore skips empty generations, 📚 lists every generation.

⚙️ One-time setup needed (≈5 min, once): create Google Cloud OAuth Client ID → paste into assets/js/gdrive-config.js. Full recipe in that file header + Deployment Phase 4c. After commit, this card shows Connect button everywhere.

Rotation keeps newest 5 generations. Restore merges (union) — never deletes local work. Drive + Cloud Sync independent; use either or both.

☁️ Cloud Sync — same fleet on every device off
